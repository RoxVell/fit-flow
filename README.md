# FitFlow

Mobile-first fitness tracking PWA. Dashboard, workout logger (timer, rest timer, swipe-to-delete), cardio log, programs (PPL / Upper-Lower / AI-generated), and progress charts (general index, body-part breakdown, per-exercise e1RM/volume, body weight, PRs).

Built with Next.js 16, Tailwind CSS v4, ShadCN, TanStack Query, Zustand, Recharts, Framer Motion. All data is mocked — no backend required.
